WEB PUSH

Privacidade dos alertas

Os alertas esportivos do Fórmula do Gol são opcionais e não exigem conta, login, senha, nome, telefone ou e-mail.

Dados técnicos armazenados

Quando você ativa notificações, o sistema armazena um identificador aleatório deste navegador, a assinatura técnica Web Push fornecida pelo navegador e as preferências escolhidas, como clubes, partidas e tipos de notificação acompanhados. Esses dados ficam no backend Cloudflare do Fórmula do Gol e são usados somente para entregar os alertas solicitados.

Entrega da notificação

O navegador e o serviço de push do sistema operacional participam tecnicamente da entrega. A ESPN é consultada pelo backend apenas como fonte dos eventos esportivos; a assinatura do seu aparelho não é enviada à ESPN.

Cancelamento e limpeza

Você pode desativar os alertas em Alertas. Assinaturas que o serviço de push informar como expiradas ou inexistentes também são desativadas automaticamente.

Finalidade

As informações técnicas de Web Push e as preferências não são usadas para criar conta de usuário nem para autenticação. O recurso existe exclusivamente para selecionar e entregar notificações esportivas solicitadas pelo próprio usuário.

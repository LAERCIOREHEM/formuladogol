# FDG-INC-20261008 — AF_COVERAGE_MISMATCH
**Sintoma:** validação esperava jogos já FINAL entre partidas restantes.  
**Causa raiz:** regressão de estado esportivo; não erro matemático do AF.  
**Regra:** calendário restante e probabilidades pré-jogo devem ter exatamente o mesmo conjunto por identidade esportiva.

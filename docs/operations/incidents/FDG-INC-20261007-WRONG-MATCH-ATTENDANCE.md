# FDG-INC-20261007 — SOURCE_IDENTITY_MISMATCH
**Sintoma:** público/renda de outra partida foi associado ao evento correto.  
**Causa:** URL descoberta era aceita sem prova suficiente de identidade.  
**Regra:** IA descobre URLs; gravação exige abrir a fonte, Match Identity Gate e extração limitada ao contexto daquele confronto.

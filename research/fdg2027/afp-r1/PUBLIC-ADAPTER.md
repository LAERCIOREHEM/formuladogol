# AFP public adapter
The SL02 Jogadores route has a conditional AF-Player tab. No rating data or tab is exposed before the build verifies approved-release.json and approved-ranking.json with four explicit evidence gates and exact SHA-256. A validated release injects its hash into the HTML and copies only the allowlisted derived JSON to sl02/af-player.json. Browser checks the hash and fails back to existing statistics. No source IDs or raw match fields allowed. AF-Player becomes the default only with a real certified release; explicit assists deep link preserved. Existing data, AF1.3 and 2027 state remain untouched. The files approved-release.json and approved-ranking.json are intentionally absent. Synthetic contract fixtures are tests only, never public.

# FDG-AFP-R2 — public presentation only

AF Index equals the existing hash-validated position percentile, with up to three decimal places. No E04 recalculation, new data, provider calls, or model promotion. Competition rank in the filtered display is based on exact stored percentiles (1,1,3); ties display by role order G/D/M/F, then name and club. The original position_rank remains the season cohort rank, never recomputed by filters. Leaders represent each eligible role in the filtered view; all equal leaders appear. Labels describe percentile bands only, not calibrated absolute ability. Experimental status, source cutoff, confidence, missing axes and data limits remain explicit. Technical rating is in Raio-X. Production season 2026 and AF-Previsão remain unchanged. Browser tests cover synthetic ties, missing/tampered payloads, real dataset ordering, rank integrity, all filters, 14 viewport/theme cases, and existing public smoke.

# E08 — Historical Backtesting
Protocol.json is frozen before any private result is scored. E07 replay is retrospective and previously examined, not a fresh holdout. Primary comparison uses all 740 2025–26 fixtures with fallback; 2024 is warmup. Context at kickoff versus baseline at local day start is a reconstructed horizon, not proof of identical real pre-match availability. Bootstrap resamples paired season/ISO-week clusters, descriptive uncertainty only. Brier sum over 3 classes, natural log loss, native modal/Top3, fixed calibration bins. Compare candidate variants separately; common-case combined/leave-one-group-out only if training >=100. XI is retrospective with original E05 gate and E07 minimum 100, incremental to competitive; no lowering minimum or imputing missing XI. Documentary archive pinned at E07 commit, validated separately, never joined to provider fixture IDs. Sensitivity to native vs expanded matrix tail, stratification by observed outcome, favorite, coverage, calendar half, club/role (private). No promotion, no production changes, no sports APIs. Prospective protocol requires independent timestamps, frozen parameters and a distinct authorization. No new season execution now.
